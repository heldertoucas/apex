# Manual de Implementação - Capítulo 6: Execução Pedagógica (Detalhado)
**Aplicação:** Academia Digital  
**Versão do Guia:** 3.0 (Passo-a-Passo Beginner Friendly)  
**Objetivo:** Criar o "Portal do Formador" – as ferramentas digitais para gerir a sala de aula (Presenças, Notas e Medalhas).

---

## Introdução
Este guia foi desenhado para ser executado **exatamente** como está escrito. Não precisa de interpretar, apenas siga os cliques.
Vamos construir 4 páginas principais:
1.  **Dashboard "Minhas Turmas":** A página de entrada do formador.
2.  **Sessões:** Onde se marca quem faltou.
3.  **Pauta da Turma:** Onde se dão as notas.
4.  **Gestão de Medalhas:** Onde se atribuem prémios.

---

## Parte 1: Preparar a Base de Dados (SQL)

Antes de criar as páginas, precisamos das "gavetas" (tabelas) onde os dados serão guardados.

### Passo 1.1: Aceder ao SQL Workshop
1.  Faça login no seu Workspace APEX.
2.  No menu superior, clique em **SQL Workshop**.
3.  Selecione **SQL Scripts**.

### Passo 1.2: Criar o Script
1.  Clique no botão verde **Create** (canto superior direito).
2.  **Script Name:** Digite `06_Pedagogia`.
3.  **Opção A (Recomendada):** Abra o ficheiro `06_Pedagogia.sql` que está na pasta `devops/v7` do seu computador, copie todo o conteúdo e cole na área de texto.
4.  **Opção B (Copiar daqui):** Se preferir, copie o código abaixo (que é igual ao ficheiro):

```sql
-- 06_Pedagogia.sql
-- Capítulo 6: Execução Pedagógica (Unified Script)
-- Inclui tabelas para Presenças, Avaliações e Gestão de Medalhas

-- 1. Presenças (Assiduidade por Sessão)
CREATE TABLE Presencas (
    ID_Presenca NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY PRIMARY KEY,
    ID_Sessao NUMBER NOT NULL,
    ID_Matricula NUMBER NOT NULL,
    ID_Estado_Presenca NUMBER, -- Opcional: Lookup para 'Presente', 'Falta Injustificada', etc.
    Horas_Assistidas NUMBER,
    Data_Registo TIMESTAMP DEFAULT SYSTIMESTAMP,
    FOREIGN KEY (ID_Sessao) REFERENCES Sessoes(ID_Sessao) ON DELETE CASCADE,
    FOREIGN KEY (ID_Matricula) REFERENCES Matriculas(ID_Matricula) ON DELETE CASCADE
);

-- 2. Avaliações (Notas por Módulo)
CREATE TABLE Avaliacoes_Modulo (
    ID_Avaliacao NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY PRIMARY KEY,
    ID_Matricula NUMBER NOT NULL,
    ID_Modulo NUMBER NOT NULL,
    Nota_Valor NUMBER,
    Feedback_Texto CLOB,
    Aprovado CHAR(1) CHECK (Aprovado IN ('S', 'N')),
    Data_Avaliacao DATE DEFAULT SYSDATE,
    FOREIGN KEY (ID_Matricula) REFERENCES Matriculas(ID_Matricula) ON DELETE CASCADE,
    FOREIGN KEY (ID_Modulo) REFERENCES Modulos(ID_Modulo) ON DELETE CASCADE
);

-- 3. Badges Conquistados (Histórico do Aluno)
CREATE TABLE Badges_Conquistados (
    ID_Badge_Aluno NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY PRIMARY KEY,
    ID_Matricula NUMBER NOT NULL,
    ID_Medalha NUMBER NOT NULL,
    ID_Turma NUMBER NOT NULL,
    Data_Conquista DATE DEFAULT SYSDATE,
    URL_Evidencia VARCHAR2(500),
    Token_Validacao VARCHAR2(100),
    FOREIGN KEY (ID_Matricula) REFERENCES Matriculas(ID_Matricula) ON DELETE CASCADE,
    FOREIGN KEY (ID_Medalha) REFERENCES Catalogo_Medalhas(ID_Medalha) ON DELETE CASCADE,
    FOREIGN KEY (ID_Turma) REFERENCES Turmas(ID_Turma) ON DELETE CASCADE
);

-- 4. Turma Medalhas Elegiveis (Quais medalhas o formador pode dar nesta turma)
CREATE TABLE Turma_Medalhas_Elegiveis (
    ID_Turma NUMBER NOT NULL,
    ID_Medalha NUMBER NOT NULL,
    Selecionado_Por VARCHAR2(100),
    Data_Selecao DATE DEFAULT SYSDATE,
    PRIMARY KEY (ID_Turma, ID_Medalha),
    FOREIGN KEY (ID_Turma) REFERENCES Turmas(ID_Turma) ON DELETE CASCADE,
    FOREIGN KEY (ID_Medalha) REFERENCES Catalogo_Medalhas(ID_Medalha) ON DELETE CASCADE
);

-- Indices para Performance
CREATE INDEX IDX_Presencas_Sessao ON Presencas(ID_Sessao);
CREATE INDEX IDX_Avaliacoes_Matricula ON Avaliacoes_Modulo(ID_Matricula);
CREATE INDEX IDX_Badges_Aluno ON Badges_Conquistados(ID_Matricula);
```
5.  Clique em **Run** (botão verde no topo, à direita).
6.  Na janela de confirmação, clique novamente em **Run Now**.
7.  Verifique se aparece a mensagem "Statements Processed" (deve criar 4 tabelas).

## Parte 2: A Página "Minhas Turmas"

Vamos criar a página inicial do Formador, onde ele vê os seus cursos em cartões bonitos.

### Passo 2.1: Criar a Página
1.  Vá ao **App Builder** e entre na sua aplicação "Academia Digital".
2.  Clique em **Create Page** (botão grande no meio).
3.  Selecione **Cards**.
4.  **Page Number:** Deixe o sugerido (ex: 10 ou similar).
5.  **Page Name:** Escreva `Minhas Turmas`.
6.  **Table / View Name:** Selecione a tabela `TURMAS` (pode escrever para filtrar).
7.  Clique em **Next**.

### Passo 2.2: Configurar o Menu
1.  **Navigation Preference:** Selecione "Create a new navigation menu entry".
2.  **Parent Navigation Menu Entry:** Se já criou o grupo "Pedagógico", selecione-o. Senão, deixe vazio (vamos arrumar depois).
3.  **New Navigation Menu Entry:** Deixe `Minhas Turmas`.
4.  Clique em **Next**.

### Passo 2.3: Configurar os Cartões (Cards)
Aqui definimos o que aparece escrito em cada cartão.
1.  **Report Source:** Deixe SQL Query ou Table (local).
2.  **Card Title:** Selecione a coluna `CODIGO` (ex: TURMA-2026-001).
3.  **Card Body:** Selecione a coluna `DATA_INICIO` (ou deixe vazio por agora).
4.  Clique em **Create Page**.

### Passo 2.4: Melhorar os Cartões (Avançado)
Agora que a página abriu no Editor:
1.  Na árvore à esquerda (Rendering), clique na região **Cards** (provavelmente chama-se "Minhas Turmas").
2.  No painel da direita (Attributes), procure a secção **Card**.
3.  **Title Column:** `CODIGO`.
4.  **Subtitle Column:** Selecione `- Select -` (ou ID_CURSO se quiser).
5.  **Body Column:** Vamos fazer algo mais bonito com SQL depois, por agora deixe estar.
6.  **Icon Source:** Initials.
7.  **Icon Column:** `CODIGO`.
8.  **Badge Column:** `ID_ESTADO_TURMA` (para mostrar se está "Planeada" ou "Decorrer").
9.  **Actions (O Link):**
    *   No painel da direita, desça até **Actions**.
9.  **Actions (O Link):**
    *   No painel da direita, desça até **Actions**.
    *   Clique em **Create Action** (Full Card).
    *   **Type:** `Redirect to Page in this Application`.
    *   **Target:** Clique no ícone do Link.
        *   **Page:** Selecione a página `Sessões` (se não aparecer o nome, escreva o número da página, ex: `20` ou `12`).
        *   **Clear Cache:** Digite o número da página de destino (ex: `12`). (Isto é importante para limpar filtros antigos).
        *   **Set Items:** *Deixe vazio por agora.* (Como criou a página exatamente pelo guia padrão do APEX, ela ainda não tem campos "invisíveis" para receber o ID da Turma. O link vai abrir a página com todas as sessões. Mais tarde, no "Polimento", podemos adicionar o filtro).
    *   Clique **OK**.

## Parte 3: Página de Sessões (Presenças)

A página mais importante. É aqui que o formador diz "O João faltou".

### Passo 3.1: Iniciar o Wizard
1.  Volte ao **App Builder** (topo da página).
2.  Clique **Create Page**.
3.  Selecione **Master-Detail**.

### Passo 3.2: Configurar o Layout e Fonte
1.  **Page Type:** Escolha **Stacked** (Empilhado).
2.  **Page Number:** Deixe automático.
3.  **Page Name:** `Sessões`.
4.  Clique **Next**.

### Passo 3.3: Configurar a Tabela Mestre (Sessões)
1.  **Navigation Preference:** Se aparecer, escolha "Do not associate..." (ou associe se preferir).
2.  **Source Type:** `Table`.
3.  **Table / View Name:** Selecione `SESSOES`.
4.  **Primary Key Column(s):** O APEX deve detetar `ID_SESSAO` automaticamente.
5.  Clique **Next**.

### Passo 3.4: Configurar a Tabela Detalhe (Presenças)
1.  **Show Only Related Tables:** Deixe marcado (ajuda a filtrar).
2.  **Table / View Name:** Selecione `PRESENCAS`.
3.  **Primary Key Column:** O APEX deve detetar `ID_PRESENCA`.
4.  **Master Detail Foreign Key:** Selecione `ID_SESSAO` (é a coluna na tabela `PRESENCAS` que aponta para a Sessão).
5.  Clique **Create Page**.

### Passo 3.5: Ajustar o Detalhe (Presenças) para ser "Editável"
O APEX criou um "Interactive Grid" para as presenças. Vamos configurá-lo.
1.  Na árvore esquerda (Rendering), procure a região **Presencas** (deve estar em baixo).
2.  Expanda a região **Columns**.
3.  **Esconder colunas técnicas:**
    *   Clique em `ID_PRESENCA`, vá à direita e mude **Type** para `Hidden`.
    *   Clique em `ID_SESSAO`, mude **Type** para `Hidden`.
    *   Clique em `ID_MATRICULA`, mude **Type** para `Popup LOV` (para vermos o nome do aluno!).
        *   **LOV Type:** SQL Query.
        *   **SQL Query:** `SELECT Entidades.Nome_Completo as d, Matriculas.ID_Matricula as r FROM Matriculas JOIN Entidades ON Matriculas.ID_Aluno = Entidades.ID_Entidade`
        *   **Display Value:** `d`
        *   **Return Value:** `r`
4.  **Coluna Horas Assistidas:**
    *   Clique em `HORAS_ASSISTIDAS`.
    *   **Heading:** Escreva `Horas`.
    *   **Type:** Number Field.

### Passo 3.6: O Botão Mágico "Gerar Lista"
Quando o formador abre a aula, a lista está vazia. Precisamos de um botão que diga: "Vai buscar todos os alunos desta turma e põe aqui".

1.  Na árvore esquerda, clique com o botão direito na região **Presencas**.
2.  Escolha **Create Button**.
3.  **Button Name:** `BTN_GERAR_LISTA`.
4.  **Label:** `Gerar Lista de Alunos`.
5.  **Position:** Edit (Right of Interactive Grid Toolbar).
6.  **Behavior > Action:** `Submit Page`.

**Criar a Lógica (Processo):**
1.  No topo da árvore esquerda, clique no separador **Processing** (ícone de duas setas a girar).
2.  Clique com o botão direito em **Processing** > **Create Process**.
3.  **Name:** `Gerar Presencas`.
4.  **Type:** Execute Code.
5.  **PL/SQL Code:** (Copie e cole este código exacto)
    ```sql
    -- Inserir alunos na pauta de presenças se ainda não existirem
    INSERT INTO Presencas (ID_Sessao, ID_Matricula, Horas_Assistidas)
    SELECT :P_ID_SESSAO, m.ID_Matricula, 0
      FROM Matriculas m, Sessoes s, Turmas t
     WHERE s.ID_Sessao = :P_ID_SESSAO
       AND s.ID_Turma = t.ID_Turma
       AND m.ID_Turma = t.ID_Turma
       AND m.ID_Estado_Matricula IN (SELECT ID_Estado_Matricula FROM Tipos_Estado_Matricula WHERE Codigo = 'ATIVA')
       AND NOT EXISTS (
           SELECT 1 FROM Presencas p 
            WHERE p.ID_Matricula = m.ID_Matricula 
              AND p.ID_Sessao = s.ID_Sessao
       );
    ```
    *Dica: Substitua `:P_ID_SESSAO` pelo nome real do item da página mestre (ex: check se é `:P12_ID_SESSAO`). O APEX sugere o nome se começar a escrever `:P`.
    *   (Assumindo que a página é a 12 de acordo com o wizard, confirme o número).
6.  **Server-side Condition:**
    *   **When Button Pressed:** `BTN_GERAR_LISTA`.

## Parte 4: Pauta da Turma (Avaliações)

Uma grelha tipo Excel para lançar notas.

### Passo 4.1: Criar Página em Branco
1.  **Create Page** > **Interactive Grid**.
2.  **Page Name:** `Pauta de Avaliação`.
3.  **Table:** `AVALIACOES_MODULO`.
4.  Clique **Next** e **Create Page**.

### Passo 4.2: Fazer a Query Amigável
A tabela `AVALIACOES_MODULO` só tem IDs. Ninguém sabe quem é o aluno "453". Vamos mudar para uma query SQL que mostre nomes.
1.  Selecione a região **Pauta de Avaliação**.
2.  No painel direito, mude **Source > Type** para `SQL Query`.
3.  Cole:
    ```sql
    SELECT a.ID_Avaliacao,
           a.ID_Matricula, -- Escondido, para o join
           m.ID_Turma,     -- Para filtrar
           ent.Nome_Completo as Nome_Formando, -- Para ler
           mod.Nome as Modulo,       -- Para ler
           a.Nota_Valor,   -- Para editar
           a.Feedback_Texto, -- Para editar
           a.Aprovado      -- Para editar
      FROM Avaliacoes_Modulo a
      JOIN Matriculas m ON a.ID_Matricula = m.ID_Matricula
      JOIN Entidades ent ON m.ID_Aluno = ent.ID_Entidade
      JOIN Modulos mod ON a.ID_Modulo = mod.ID_Modulo
    ```
4.  **Importante:** Vá a **Attributes** (separador no topo do painel direito) > **Edit** e ative **Enabled**.
5.  Em **Allowed Operations**, marque **Update**. (Não marque Add nem Delete, vamos gerar via botão).

### Passo 4.3: Configurar Colunas
1.  Expanda **Columns** na árvore.
2.  `ID_AVALIACAO`: Primary Key, Hidden.
3.  `ID_MATRICULA`: Hidden.
4.  `ID_TURMA`: Hidden.
5.  `NOME_FORMANDO`: Type `Text`, Heading `Formando`, **Query Only** = Yes (Active Switch "Query Only" nas propriedades Source).
6.  `MODULO`: Type `Text`, Heading `Módulo`, **Query Only** = Yes.
7.  `NOTA_VALOR`: Type `Number Field`, Heading `Nota (0-20)`.

### Passo 4.4: Criar o Item de Filtro (Dropdown)
Esta página vai abrir cheia de dados. Vamos criar um campo para escolher a turma.
1.  Na árvore à esquerda, clique com o botão direito na região **Breadcrumb Bar** e escolha **Create Page Item**.
2.  **Name:** `P_FILTRO_TURMA`.
3.  **Type:** `Popup LOV`.
4.  **List of Values > Type:** `SQL Query`.
5.  **SQL Query (do Item):** `SELECT Codigo_Turma as d, ID_Turma as r FROM Turmas ORDER BY 1`.
6.  **Display Null Value:** `Yes` (Label: "- Selecione uma Turma -").

### Passo 4.5: Ligar o Filtro à Grelha
Agora vamos dizer à Grelha para obedecer ao filtro.
1.  Na árvore à esquerda, clique na região **Pauta de Avaliação** (a Grelha principal).
2.  No painel da direita, vá a **Source > SQL Query**.
3.  Altere a query para incluir a cláusula `WHERE` no final:
    ```sql
    SELECT a.ID_Avaliacao,
           a.ID_Matricula,
           m.ID_Turma,
           ent.Nome_Completo as Nome_Formando,
           mod.Nome as Modulo,
           a.Nota_Valor,
           a.Feedback_Texto,
           a.Aprovado
      FROM Avaliacoes_Modulo a
      JOIN Matriculas m ON a.ID_Matricula = m.ID_Matricula
      JOIN Entidades ent ON m.ID_Aluno = ent.ID_Entidade
      JOIN Modulos mod ON a.ID_Modulo = mod.ID_Modulo
     WHERE m.ID_Turma = :P_FILTRO_TURMA
    ```
4.  Logo abaixo da Query, no campo **Page Items to Submit**, escreva: `P_FILTRO_TURMA` (isto é fundamental para a atualização funcionar!).

## Parte 5: Gestão de Medalhas (Pop-up)

O Formador escolhe quais as medalhas "Best Performance", "Bom Colega", etc., que vai dar nesta turma.

### Passo 5.1: Criar Página Modal
1.  **Create Page** > **Interactive Grid**.
2.  **Page Name:** `Selecionar Medalhas`.
3.  **Page Mode:** `Modal Dialog` (Janela flutuante).
4.  **Table:** `CATALOGO_MEDALHAS` (mas vamos mudar para SQL já a seguir).
5.  Clique **Create Page**.

### Passo 5.2: A Lógica da Checkbox
Queremos uma lista de medalhas com uma "caixinha" para selecionar.
1.  Mude a Source da Grid para **SQL Query**:
    ```sql
    SELECT m.ID_Medalha,
           m.Nome,
           m.URL_Imagem,
           -- Coluna mágica: verifica se já está na tabela de "Elegíveis" desta turma
           (SELECT 'S' 
              FROM Turma_Medalhas_Elegiveis tme 
             WHERE tme.ID_Medalha = m.ID_Medalha 
               AND tme.ID_Turma = :P_TURMA_ID) as Selecionado
      FROM Catalogo_Medalhas m
     WHERE m.Ativo = 'S'
    ```
2.  Precisa de um item para receber o ID da Turma. Crie um item `P_TURMA_ID` como **Hidden**.

### Passo 5.3: Configurar a Checkbox
1.  Expanda **Columns**.
2.  Clique em `SELECIONADO`.
3.  **Type:** `Checkbox`.
4.  **Heading:** `Atribuir?`.
5.  **Checked Value:** `S`.
6.  **Unchecked Value:** `N`.

### Passo 5.4: Ativar Edição na Grelha
Para podermos gravar, a grelha tem de ser "Editável".
1.  Na árvore esquerda, clique na região **Selecionar Medalhas** (ou o nome que deu à grelha).
2.  No painel da direita, clique no separador **Attributes** (no topo do painel).
3.  **Edit > Enabled:** Mude para `On` (Ativo).
4.  **Allowed Operations:** Marque apenas **Update** (Desmarque Add e Delete, pois a lista vem da SQL).

### Passo 5.5: Gravar a Seleção (Criar Processo)
Como usámos uma SQL Query, o APEX não cria o processo de gravação automático. Temos de o criar nós.

1.  Vá à tab **Processing** (ícone das setas giratórias no topo da árvore esquerda).
2.  Clique com o botão direito em **Processing** e escolha **Create Process**.
3.  **Name:** `Gravar Medalhas`.
4.  **Type:** `Interactive Grid - Automatic Row Processing`.
5.  **Settings:**
    *   **Editable Region:** Agora já deve conseguir selecionar a sua grelha (`Selecionar Medalhas`).
6.  **Target Type:** Mude de "Region Source" para `PL/SQL Code`.
7.  **PL/SQL Code:**
    ```sql
    BEGIN
        IF :SELECIONADO = 'S' THEN
            -- Se marcou 'S', insere (ou ignora se já existir)
            MERGE INTO Turma_Medalhas_Elegiveis dest
            USING (SELECT :P_TURMA_ID as t, :ID_MEDALHA as m FROM DUAL) src
            ON (dest.ID_Turma = src.t AND dest.ID_Medalha = src.m)
            WHEN NOT MATCHED THEN INSERT (ID_Turma, ID_Medalha, Selecionado_Por)
            VALUES (src.t, src.m, :APP_USER);
        ELSIF :SELECIONADO = 'N' THEN
            -- Se desmarcou, apaga
            DELETE FROM Turma_Medalhas_Elegiveis
             WHERE ID_Turma = :P_TURMA_ID
               AND ID_Medalha = :ID_MEDALHA;
        END IF;
    END;
    ```
8.  Grave a página.

## Parte 6: Polimento e Interligação (Avançado)

Agora que as páginas existem, vamos fazer com que "conversem" umas com as outras.

### Passo 6.1: Preparar a página "Sessões" para receber Filtros
Atualmente, o Diário mostra as sessões de *todas* as turmas. Vamos corrigir.

1.  Vá à página **Sessões**.
2.  **Criar Item de Filtro:**
    *   Crie um Page Item na região Breadcrumb (ou Content Body).
    *   **Name:** `P_FILTRO_TURMA_ID` (Use o prefixo da página, ex: `P12_FILTRO_TURMA_ID`).
    *   **Type:** `Hidden`.
    *   **Value Protected:** `Off` (Importante para aceitar valores via URL sem checksums complexos).
3.  **Filtrar a Query das Sessões:**
    *   Selecione a região **Sessões** (Master).
    *   Altere a **SQL Query** (ou Table -> Where Clause) para:
        ```sql
        ID_TURMA = :P_FILTRO_TURMA_ID
        ```
        *(Nota: Se usar Source Type = Table, ponha isto no campo "Where Clause". Se usar SQL Query, adicione `WHERE ID_TURMA = :P_FILTRO_TURMA_ID`)*.
    *   **Page Items to Submit:** Indique o seu item (ex: `P12_FILTRO_TURMA_ID`).
4.  **Título Dinâmico (Bónus):**
    *   Para o título da página ficar bonito (ex: "Turma: Excel 101"), pode criar outro item hidden `P_TURMA_NOME` e definir o título da página como `Diário: &P_TURMA_NOME.`.

### Passo 6.2: Configurar o Link nos Cartões (Agora a sério!)
Agora que o destino está pronto, vamos configurar o botão de partida.

1.  Vá à página **Minhas Turmas**.
2.  Selecione a região dos **Cards**.
3.  Vá a **Actions** > Selecione a ação que criou (Full Card).
4.  **Target:**
    *   **Page:** `Sessões`.
    *   **Set Items:**
        *   **Name:** `P_FILTRO_TURMA_ID` (O nome exato do item que criou no passo 6.1).
        *   **Value:** `&ID_TURMA.` (A coluna da query dos cards).
    *   **Clear Cache:** Ponha o número da página destino.
5.  Grave. Agora, ao clicar no cartão da "Turma A", o Diário abrirá apenas com as aulas da "Turma A".

### Passo 6.3: Botão "Voltar"
Não queremos que o formador fique preso.
1.  Na página **Sessões**.
2.  **Create Button** na posição `Breadcrumb Bar` (Region Body -> Previous).
3.  **Label:** `Voltar às Turmas`.
4.  **Behavior:** Redirect to Page `Minhas Turmas`.
