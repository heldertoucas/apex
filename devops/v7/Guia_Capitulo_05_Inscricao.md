## 1. Tabela de Matrículas (SQL)

A tabela `Matriculas` conecta uma Entidade (Aluno) a uma Turma.

### 1.1. Executar Script SQL
1.  Aceda ao **SQL Workshop** > **SQL Scripts**.
2.  Crie ou edite o script `05_Matriculas`.
3.  Cole o seguinte código e execute:

```sql
-- CAPÍTULO 5: MATRÍCULAS

-- Garantir que a tabela não existe (apenas para reset)
-- DROP TABLE Matriculas CASCADE CONSTRAINTS;

CREATE TABLE Matriculas (
    ID_Matricula NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY PRIMARY KEY,
    ID_Turma NUMBER NOT NULL,
    ID_Aluno NUMBER NOT NULL,
    
    -- Controlo de Acesso e Estado
    Token_Acesso VARCHAR2(50), -- Chave única p/ avaliações anónimas ou externas
    ID_Estado_Matricula NUMBER, -- Ex: Inscrito, Selecionado, Concluído
    Data_Inscricao DATE DEFAULT SYSDATE,
    
    -- Dados Pedagógicos
    Diagnostico_Respostas CLOB, -- JSON das respostas ao diagnóstico inicial
    
    -- Dados de Saída
    Data_Conclusao DATE,
    Classificacao_Final VARCHAR2(50), -- Ex: "Apto", "18 valores"
    Total_Horas NUMBER, -- Horas efetivas frequentadas
    Avaliacao_Curso NUMBER, -- 1 a 5 (Satisfação do Aluno)
    Comentario_Aluno CLOB,
    Obs_SIGO VARCHAR2(4000), -- Notas específicas para exportação oficial
    
    -- Metadata
    ID_Nivel_Experiencia NUMBER,
    
    -- Chaves Estrangeiras
    CONSTRAINT FK_Matriculas_Turma FOREIGN KEY (ID_Turma) REFERENCES Turmas(ID_Turma),
    CONSTRAINT FK_Matriculas_Entidade FOREIGN KEY (ID_Aluno) REFERENCES Entidades(ID_Entidade),
    CONSTRAINT FK_Matriculas_Estado FOREIGN KEY (ID_Estado_Matricula) REFERENCES Tipos_Estado_Matricula(ID_Estado_Matricula)
);

-- Constraint Crítica: Um aluno não pode estar matriculado duplamente na mesma turma
CREATE UNIQUE INDEX UK_Matricula_Aluno_Turma ON Matriculas(ID_Turma, ID_Aluno);
```

## 2. Interface de Matrícula em Massa (Passo-a-Passo)

Vamos criar uma página que permite escolher uma **Turma** e, em seguida, selecionar múltiplos alunos de uma lista de candidatos para os inscrever de uma só vez.

### Passo 2.1: Criar a Página
1.  No App Builder, clique em **Create Page**.
2.  Tipo: **Blank Page**.
3.  **Page Number:** (Sugestão: 50 ou próximo disponível no grupo Matrículas).
4.  **Name:** `Gestão de Matrículas em Massa`.
5.  **Breadcrumb:** `Home > Gestão de Turmas > Matrículas em Massa`.
6.  Clique em **Create Page**.

### Passo 2.2: Criar o Filtro de Seleção de Turma
Precisamos de escolher *onde* vamos inscrever os alunos.

1.  No Page Designer, na árvore à esquerda (Rendering), clique com botão direito em **Body** > **Create Region**.
    *   **Title:** `Contexto de Trabalho`
    *   **Template:** `Standard`
2.  Dentro desta região, crie um **Page Item**:
    *   **Name:** `P50_ID_TURMA` (ajuste o número 50 ao da sua página).
    *   **Type:** `Select List`.
    *   **Label:** `Selecionar Turma`.
    *   **List of Values:**
        *   **Type:** `SQL Query`.
        *   **SQL Query:**
            ```sql
            SELECT 
                t.Codigo_Turma || ' - ' || c.Nome as d, 
                t.ID_Turma as r
            FROM Turmas t
            JOIN Cursos c ON t.ID_Curso = c.ID_Curso
            WHERE t.ID_Estado_Turma IN (SELECT ID_Estado_Turma FROM Tipos_Estado_Turma WHERE Codigo IN ('PLANEADA', 'CONFIRMADA'))
            ORDER BY t.Data_Inicio DESC
            ```
    *   **Display Extra Values:** `No`.
    *   **Null Display Value:** `- Selecione uma Turma -`.
3.  **Modern UX (Dynamic Action):**
    *   No item `P50_ID_TURMA`, vá a **Behavior** > **Page Action on Selection**.
    *   Escolha `None` (Não queremos recarregar a página toda).
    *   Isto é mais rápido e suave. Vamos configurar a atualização automática no próximo passo.

### Passo 2.3: Região 1 - Quem já está inscrito? (Visualização)
Para evitar erros, mostramos quem já pertence à turma.

1.  Crie uma nova Região abaixo de "Contexto de Trabalho".
2.  **Title:** `Alunos Matriculados`.
3.  **Type:** `Interactive Grid`.
4.  **Source:**
    *   **Type:** `SQL Query`.
    *   **SQL Query:** 
        ```sql
        ```sql
        SELECT 
            m.ID_Matricula, -- PK (Hidden)
            m.ID_Aluno,     -- ID para Facilitação de Link (Hidden)
            e.Nome_Completo as "Nome do Aluno",
            e.Email,
            tem.Descricao as "Estado",
            m.Data_Inscricao,
            
            -- Colunas de Controlo (Enriquecimento)
            CASE WHEN m.Diagnostico_Respostas IS NOT NULL THEN 'Sim' ELSE 'Não' END as "Tem Diagnóstico?",
            
            -- Histórico: Que outros cursos lhe interessam?
            (SELECT VPN_LISTAGG(c.Codigo) 
             FROM Inscricoes i 
             JOIN Cursos c ON i.ID_Curso = c.ID_Curso 
             WHERE i.ID_Entidade = m.ID_Aluno) as "Outros Interesses",
             
            m.ID_Turma
        FROM Matriculas m
        JOIN Entidades e ON m.ID_Aluno = e.ID_Entidade
        LEFT JOIN Tipos_Estado_Matricula tem ON m.ID_Estado_Matricula = tem.ID_Estado_Matricula
        WHERE m.ID_Turma = :P50_ID_TURMA
        ```
        *(Nota: Se a função VPN_LISTAGG não existir, use LISTAGG nativo ou apenas COUNT)*
    *   **Page Items to Submit:** `P50_ID_TURMA`.
5.  **Attributes (Separador Attributes da Grid):**
    *   **Edit:** `Disabled` (Para esta página, queremos apenas ver).
    *   **Toolbar:** Desligue a maioria dos botões, deixe apenas Search e Refresh.
6.  **Server-side Condition (Opcional):**
    *   Type: `Item is NOT NULL`.
    *   Item: `P50_ID_TURMA`.
    *   *(Isto faz com que a lista só apareça depois de escolhermos uma turma)*.

### Passo 2.4: Região 2 - Candidatos Disponíveis
Vamos destacar quem tem **Inscrição** no curso.

1.  **Source SQL Query:** 
    ```sql
    SELECT 
        APEX_ITEM.CHECKBOX2(p_idx => 1, p_value => e.ID_Entidade) as "Selecionar",
        e.Nome_Completo,
        e.Email,
        e.NIF,
        
        -- Colunas de Sistema (Master IDs)
        ins.ID_Inscricao as "ID Candidatura",
        
        -- Informação Extra: Quando é que manifestou interesse?
        TO_CHAR(ins.Data_Registo, 'DD/MM/YYYY') as "Data Interesse",

        -- Coluna Calculada: Prioridade Explícita
        CASE 
            -- Nível 1: Queria especificamente ESTA turma
            WHEN ins.ID_Turma_Preferencia = :P50_ID_TURMA THEN
                 '<span class="u-success-text u-bold" style="font-size: 1.1em;"><span class="fa fa-star"></span> Escolheu esta Turma</span>'
            
            -- Nível 2: Queria este Curso (Inscrição Genérica)
            WHEN ins.ID_Inscricao IS NOT NULL THEN 
                '<span class="u-info-text u-bold"><span class="fa fa-check-circle"></span> Escolheu o Curso</span>' 
            
            -- Nível 3: Geral (Sem inscrição)
            ELSE 
                '<span class="u-normal-text" style="opacity: 0.7;">População Geral</span>' 
        END as "Prioridade"
        
    FROM Entidades e
    -- Join Inteligente
    LEFT JOIN Turmas t_atual ON t_atual.ID_Turma = :P50_ID_TURMA
    -- Verificar Inscrição (Match no Curso)
    LEFT JOIN Inscricoes ins ON ins.ID_Entidade = e.ID_Entidade 
                            AND ins.ID_Curso = t_atual.ID_Curso
    WHERE e.Ativo = 'S'
    -- Excluir quem já está matriculado nesta turma
    AND NOT EXISTS (
        SELECT 1 FROM Matriculas m 
        WHERE m.ID_Aluno = e.ID_Entidade 
        AND m.ID_Turma = :P50_ID_TURMA
    )
    -- Filtro de Segurança: Excluir Administradores e Equipa Formativa (Staff)
    AND NOT EXISTS (
        SELECT 1 FROM Papeis_Entidade pe 
        WHERE pe.ID_Entidade = e.ID_Entidade 
        AND pe.Codigo_Papel IN ('ADMIN', 'FORMADOR', 'COORDENADOR')
    )
    -- Prioridade Multi-Nível (Turma > Curso > Geral) e depois Data de Interesse (Mais antigos primeiro)
    ORDER BY 
        (CASE 
            WHEN ins.ID_Turma_Preferencia = :P50_ID_TURMA THEN 1 
            WHEN ins.ID_Inscricao IS NOT NULL THEN 2 
            ELSE 3 
        END),
        ins.Data_Registo ASC NULLS LAST, -- Priorizar quem chegou primeiro
        e.Nome_Completo
    ```
2.  **Configuração da Coluna "Prioridade":**
    *   **Type:** `Plain Text`.
    *   **Escape special characters:** `No` (Para renderizar o HTML do ícone).
    *   **Heading:** `Prioridade`.
    *   **Alignment:** `Center`.

    *   **Alignment:** `Center`.

> [!TIP]
> **Colunas Novas Não Aparecem?**
> O APEX guarda as definições do relatório do utilizador (colunas visíveis, ordem, etc.).
> Se alterou o SQL e as colunas novas não aparecem na app:
> 1.  Na Toolbar do Relatório Interativo, clique em **Actions**.
> 2.  Escolha **Columns**.
> 3.  Passe as novas colunas (`Prioridade`, `ID Candidatura`, `Data Interesse`) da esquerda (Do Not Display) para a direita (Display in Report).
> 4.  **Alternativa Rápida:** Actions > Report > **Reset**.
> 5.  Para gravar para todos os utilizadores: Actions > Report > Save Report > **As Default Report Settings**.

**Nota:** Assim, os candidatos que mostraram interesse aparecem no topo da lista com um ícone verde.
6.  **Configuração da Checkbox (Crucial para Interactive Report):**
    *   Na árvore à esquerda, expanda **Columns**.
    *   Clique na coluna `"Selecionar"`.
    *   **Heading:** `Selecionar` (Nota: O "Select All" com Javascript pode conflituar com filtros do IR, por isso vamos usar simples).
    *   **Security > Escape special characters:** **No** (CRÍTICO: Sem isto o IR mostra o código HTML do input).
    *   **Alignment:** `Center`.
    *   **Enable Users to:** Desligue Sort, Filter, Highlight para esta coluna (não faz sentido filtrar por checkbox).

### Passo 2.5: O Botão e o Processo de Gravação
Criar a ação que efetivamente insere os dados.

1.  **Botão:**
    *   Na região "Candidatos Disponíveis", crie um botão.
    *   **Name:** `BTN_MATRICULAR`.
    *   **Label:** `Matricular Selecionados`.
    *   **Position:** `Information` ou `Right of Region Title`.
    *   **Hot:** `Yes`.

2.  **Processo (Processing):**
    *   Vá ao separador **Processing** (ícone das setas giratórias à esquerda).
    *   Clique direito em **Processing** > **Create Process**.
    *   **Name:** `Processar Matrícula em Massa`.
    *   **Type:** `Execute Code`.
    *   **PL/SQL Code:**
        ```sql
        ```sql
        DECLARE
            v_Count NUMBER := 0;
            v_ID_Estado_Inscrito NUMBER;
            v_ID_Curso NUMBER;
            v_Diagnostico CLOB;
        BEGIN
            -- 1. Obter o Estado 'SELECIONADO' e o Curso da Turma
            SELECT ID_Estado_Matricula INTO v_ID_Estado_Inscrito 
            FROM Tipos_Estado_Matricula WHERE Codigo = 'SELECIONADO';
            
            SELECT ID_Curso INTO v_ID_Curso 
            FROM Turmas WHERE ID_Turma = :P50_ID_TURMA;

            -- 2. Loop pelas checkboxes selecionadas (Array global F01)
            FOR i IN 1..APEX_APPLICATION.G_F01.COUNT LOOP
                
                -- 2b. Tentar copiar o Diagnóstico da Inscrição (se existir)
                v_Diagnostico := NULL;
                BEGIN
                    SELECT Respostas_Diagnostico INTO v_Diagnostico 
                    FROM Inscricoes 
                    WHERE ID_Entidade = APEX_APPLICATION.G_F01(i) 
                    AND ID_Curso = v_ID_Curso;
                EXCEPTION WHEN NO_DATA_FOUND THEN NULL;
                END;

                -- 3. Inserir Registo com Diagnóstico
                INSERT INTO Matriculas (
                    ID_Turma, 
                    ID_Aluno, 
                    ID_Estado_Matricula,
                    Data_Inscricao,
                    Diagnostico_Respostas
                ) VALUES (
                    :P50_ID_TURMA,
                    APEX_APPLICATION.G_F01(i), -- ID da Entidade vindo da checkbox
                    v_ID_Estado_Inscrito,
                    SYSDATE,
                    v_Diagnostico
                );
                
                v_Count := v_Count + 1;
            END LOOP;
            
            -- 4. Mensagem de Sucesso Personalizada
            apex_application.g_print_success_message := v_Count || ' alunos matriculados com sucesso!';
            
        EXCEPTION WHEN OTHERS THEN
            apex_error.add_error(
                p_message => 'Erro ao processar matrículas: ' || SQLERRM,
                p_display_location => apex_error.c_inline_in_notification
            );
        END;
        ```
    *   **Server-side Condition:**
        *   **When Button Pressed:** `BTN_MATRICULAR`.

### Passo 2.6: Criar a Dynamic Action de Atualização
Para que as listas atualizem automaticamente quando muda a turma, sem recarregar a página:

1.  Clique com o botão direito no Item `P50_ID_TURMA`.
2.  Escolha **Create Dynamic Action**.
3.  **Name:** `Ao Mudar Turma`.
4.  **Event:** `Change`.
5.  **Selection Type:** `Item`.
6.  **Item(s):** `P50_ID_TURMA`.
7.  **True Actions:**
    *   **Action 1 (Refresh Grid):**
        *   **Action:** `Refresh`.
        *   **Selection Type:** `Region`.
        *   **Region:** `Alunos Matriculados`.
    *   **Action 2 (Refresh Candidates):**
        *   **Action:** `Refresh`.
        *   **Selection Type:** `Region`.
        *   **Region:** `Candidatos Disponíveis`.

**Nota Importante:** Certifique-se que em ambas as regiões (Interactive Grid e Classic Report), a propriedade **Page Items to Submit** contém `P50_ID_TURMA`. Sem isto, o refresh não envia o valor do filtro!

### Passo 2.7: Anular Matrícula (Reverter para Inscrito)
Para remover alunos da turma, vamos usar a **funcionalidade nativa** da Interactive Grid. É a forma mais robusta e não requer código extra.

1.  **Ativar Edição na Grelha:**
    *   Selecione a Região **"Alunos Matriculados"**.
    *   Vá ao separador **Attributes** (na direita).
    *   Secção **Edit**:
        *   **Enabled:** `On` (Ativado).
        *   **Allowed Operations:** Marque **apenas** `Delete Row` (Desmarque *Add Row* e *Update Row*).
        *   *Explicação:* Só queremos permitir remover matrículas, não queremos criar ou alterar dados manualmente aqui.
    *   **CRÍTICO - Definir Chave Primária:**
        *   Expanda a pasta **Columns** na árvore à esquerda.
        *   Selecione a coluna `ID_MATRICULA`.
        *   Na propriedade **Identification** > **Primary Key**, mude para **Yes**.
        *   *(Sem isto, o APEX dá erro porque não sabe que linha apagar!)*

2.  **Configurar a Toolbar:**
    *   Ainda em **Attributes** > **Toolbar**:
        *   **Buttons:** Certifique-se que `Save` está selecionado.
        *   *(Opcional)* Pode mudar o Label do botão Save para "Gravar Anulações".

3.  **Como Funciona na Prática:**
    *   O utilizador abre a página.
    *   Clica nas caixas de seleção (checkboxes) à esquerda dos alunos que quer remover.
    *   Clica no botão **Row Actions** (os 3 pontinhos na linha) e escolhe **Delete** (ou no botão "Delete" da toolbar se visível).
    *   As linhas ficam riscadas.
    *   Clica no botão **Save** (Gravar) no topo da grelha para confirmar a anulação.

4.  **Atualizar a Lista de Candidatos Automaticamente (CRÍTICO):**
    *   Como a Grelha usa AJAX (não recarrega a página), a lista de baixo não sabe que o aluno foi "libertado". Vamos corrigir isso:
    *   Crie uma nova **Dynamic Action** na página.
    *   **Name:** `Ao Gravar Anulação`.
    *   **Event:** `Save` (Interative Grid).
    *   **Selection Type:** `Region`.
    *   **Region:** `Alunos Matriculados`.
    *   **True Action:**
        *   **Action:** `Refresh`.
        *   **Selection Type:** `Region`.
        *   **Region:** `Candidatos Disponíveis`.

**Nota:** Ao apagar a linha da tabela `Matriculas`, o aluno perde a matrícula e volta automaticamente ao estado de "Candidato Disponível" na lista de baixo (após refresh), porque a pré-inscrição continua lá.
