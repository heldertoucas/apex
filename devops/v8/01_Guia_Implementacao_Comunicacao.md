# Guia de Implementação: Sistema de Comunicação e Automação (V8)

**Objetivo:** Implementar um sistema que permita criar templates de email, enviar notificações manuais a partir de uma Turma, e automatizar comunicações de ciclo de vida (ex: lembretes).
**Nível:** Principiante/Intermédio
**Pré-requisitos:** Ter o APEX App Builder aberto e acesso ao SQL Workshop.

---

## Parte 1: Base de Dados (O "Cérebro")

Antes de criar páginas, precisamos das tabelas e da lógica (PL/SQL).

### Passo 1.1: Criar as Tabelas
Vá ao **SQL Workshop > SQL Commands**, copie este código e clique em **Run**.

```sql
-- 1. Tabela de Templates (Modelos)
CREATE TABLE Modelos_Comunicacao (
    ID_Modelo       NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY PRIMARY KEY,
    Codigo_Ref      VARCHAR2(50) NOT NULL, -- Ex: 'BOAS_VINDAS'
    Assunto         VARCHAR2(200) NOT NULL,
    Corpo_HTML      CLOB,
    Contexto        VARCHAR2(20) DEFAULT 'GERAL', -- 'TURMA', 'ALUNO', 'GERAL'
    ID_Curso        NUMBER, -- Para "Overrides" específicos
    Ativo           CHAR(1) DEFAULT 'S' CHECK (Ativo IN ('S','N')),
    CONSTRAINT UK_Modelo_Ref_Curso UNIQUE (Codigo_Ref, ID_Curso)
);

-- 2. Tabela de Fila de Envio (Log & Queue)
CREATE TABLE Log_Comunicacoes (
    ID_Log          NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY PRIMARY KEY,
    Remetente       VARCHAR2(100) DEFAULT 'noreply@academiadigital.pt',
    Destinatario    VARCHAR2(255) NOT NULL,
    Assunto         VARCHAR2(200),
    Corpo_HTML      CLOB,
    Data_Criacao    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    Data_Agendada   TIMESTAMP DEFAULT CURRENT_TIMESTAMP, -- Para agendamento
    Data_Envio      TIMESTAMP,
    Estado          VARCHAR2(20) DEFAULT 'PENDENTE', -- PENDENTE, ENVIADO, ERRO
    Erro_Msg        VARCHAR2(4000),
    Contexto_Origem VARCHAR2(50) -- Ex: 'TURMA:10'
);

-- 3. Inserir Dados de Exemplo (Seed Data)
INSERT INTO Modelos_Comunicacao (Codigo_Ref, Assunto, Contexto, Corpo_HTML)
VALUES (
    'BOAS_VINDAS', 
    'Bem-vindo à Academia: #CURSO#', 
    'TURMA',
    '<p>Olá <strong>#NOME#</strong>,</p><p>Confirma-se a tua inscrição na turma #TURMA#.</p>'
);
```

### Passo 1.2: Criar o Pacote de Lógica (PL/SQL)
Este pacote vai gerir a substituição dos `#PLACEHOLDERS#` e o envio. Execute no **SQL Commands**.

```sql
CREATE OR REPLACE PACKAGE PKG_COMUNICACAO AS
    -- Função para substituir variáveis (O "Motor")
    FUNCTION Processar_Template(
        p_modelo_id IN NUMBER,
        p_aluno_id  IN NUMBER DEFAULT NULL,
        p_turma_id  IN NUMBER DEFAULT NULL
    ) RETURN CLOB;

    -- Procedimento para Agendar um Email (Colocar na Fila)
    PROCEDURE Agendar_Email(
        p_para          IN VARCHAR2,
        p_assunto       IN VARCHAR2,
        p_corpo         IN CLOB,
        p_data_agendada IN TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
        p_origem        IN VARCHAR2 DEFAULT NULL
    );

    -- Procedimento para Disparar Emails Pendentes (Será usado pela Automação)
    PROCEDURE Processar_Fila;
END PKG_COMUNICACAO;
/

CREATE OR REPLACE PACKAGE BODY PKG_COMUNICACAO AS

    FUNCTION Processar_Template(
        p_modelo_id IN NUMBER,
        p_aluno_id  IN NUMBER DEFAULT NULL,
        p_turma_id  IN NUMBER DEFAULT NULL
    ) RETURN CLOB IS
        l_html      CLOB;
        l_assunto   VARCHAR2(200);
        l_nome      VARCHAR2(200);
        l_curso     VARCHAR2(200);
        l_data_inicio VARCHAR2(20);
    BEGIN
        -- 1. Buscar o template bruto
        SELECT Corpo_HTML INTO l_html FROM Modelos_Comunicacao WHERE ID_Modelo = p_modelo_id;

        -- 2. Buscar dados do Aluno (se aplicável)
        IF p_aluno_id IS NOT NULL THEN
            SELECT Nome_Completo INTO l_nome FROM Entidades WHERE ID_Entidade = p_aluno_id;
            l_html := REPLACE(l_html, '#NOME#', l_nome);
        END IF;

        -- 3. Buscar dados da Turma (se aplicável)
        IF p_turma_id IS NOT NULL THEN
             -- Join simples para buscar nome do curso e data inicio
            SELECT c.Nome, t.Codigo_Turma, TO_CHAR(t.Data_Inicio, 'DD/MM/YYYY')
            INTO l_curso, l_curso, l_data_inicio -- Simplificação: usar codigo turma como "Curso" placeholder genérico
            FROM Turmas t JOIN Cursos c ON t.ID_Curso = c.ID_Curso
            WHERE t.ID_Turma = p_turma_id;
            
            l_html := REPLACE(l_html, '#CURSO#', l_curso);
            l_html := REPLACE(l_html, '#TURMA#', l_curso); -- Variação
            l_html := REPLACE(l_html, '#DATA_INICIO#', l_data_inicio);
        END IF;

        RETURN l_html;
    EXCEPTION WHEN OTHERS THEN RETURN 'Erro ao processar template: ' || SQLERRM;
    END;

    PROCEDURE Agendar_Email(
        p_para          IN VARCHAR2,
        p_assunto       IN VARCHAR2,
        p_corpo         IN CLOB,
        p_data_agendada IN TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
        p_origem        IN VARCHAR2 DEFAULT NULL
    ) IS
    BEGIN
        INSERT INTO Log_Comunicacoes (Destinatario, Assunto, Corpo_HTML, Data_Agendada, Contexto_Origem)
        VALUES (p_para, p_assunto, p_corpo, p_data_agendada, p_origem);
    END;

    PROCEDURE Processar_Fila IS
    BEGIN
        FOR r IN (SELECT * FROM Log_Comunicacoes WHERE Estado = 'PENDENTE' AND Data_Agendada <= CURRENT_TIMESTAMP) LOOP
            BEGIN
                -- Envia o email usando a API nativa do APEX
                APEX_MAIL.SEND(
                    p_to   => r.Destinatario,
                    p_from => r.Remetente,
                    p_subj => r.Assunto,
                    p_body => 'Por favor ative HTML.', -- Texto simples alternativo
                    p_body_html => r.Corpo_HTML
                );
                
                -- Se não der erro, marca como enviado
                 -- IMPORTANTE: APEX_MAIL adiciona à fila interna do APEX.
                UPDATE Log_Comunicacoes SET Estado = 'ENVIADO', Data_Envio = CURRENT_TIMESTAMP WHERE ID_Log = r.ID_Log;
            EXCEPTION WHEN OTHERS THEN
                UPDATE Log_Comunicacoes SET Estado = 'ERRO', Erro_Msg = SQLERRM WHERE ID_Log = r.ID_Log;
            END;
        END LOOP;
        -- Força o envio imediato da fila interna do APEX
        APEX_MAIL.PUSH_QUEUE;
    END;
END PKG_COMUNICACAO;
/
```

## Parte 2: Backoffice - Gestão de Templates

Vamos criar a página onde a Ana define os textos.

1.  **Criar Página:**
    *   Vá a **App Builder > Create Page**.
    *   Escolha **Interactive Report**.
    *   **Page Name:** `Modelos de Comunicação`.
    *   **Page Number:** (Sugestão: 60).
    *   Ative "Include Form Page" para criar também o formulário de edição.
    *   **Data Source:** Tabela `MODELOS_COMUNICACAO`.
2.  **Configurar o Formulário (Página de Detalhe):**
    *   Selecione o item `P61_CORPO_HTML` (assumindo pág 61).
    *   Mude o **Type** para **Rich Text Editor**.
    *   Selecione o item `P61_ID_CURSO`.
    *   Mude o **Type** para **Popup LOV**.
    *   **LOV Query:** `SELECT Nome d, ID_Curso r FROM Cursos ORDER BY 1`.
    *   **Help Text:** "Deixe vazio para ser o template padrão. Selecione um curso para criar uma exceção específica."

## Parte 3: Backoffice - Enviar Notificação (Turmas)

O "Botão Mágico" na ficha da turma.

1.  **Botão de Ação:**
    *   Vá à página de Detalhe de Turma (criada no Cap. 4).
    *   Crie um botão `NOTIFICAR_TURMA` na região de topo (Breadcrumb Bar).
    *   **Behavior > Action:** Redirect to Page.
    *   **Target:** Vamos criar uma nova página "Wizard" (Pág 62).

2.  **Criar o Wizard de Envio (Página 62):**
    *   Crie uma **Blank Page**. Nome: `Enviar Notificação`. Mode: **Modal Dialog**.
    *   **Região 1 (Seleção):**
        *   Item `P62_ID_TURMA` (Hidden).
        *   Item `P62_MODELO` (Select List). LOV: `SELECT Assunto d, ID_Modelo r FROM Modelos_Comunicacao WHERE Contexto = 'TURMA'`.
        *   Item `P62_DATA_AGENDAMENTO` (Date Picker). Label: "Enviar Quando?". Default: `sysdate` (Agora).
    *   **Região 2 (Alunos):**
        *   Crie um **Interactive Grid**.
        *   **Source:**
            ```sql
            SELECT m.ID_Entidade, e.Nome_Completo, e.Email, 'S' as Enviar
            FROM Matriculas m 
            JOIN Entidades e ON m.ID_Entidade = e.ID_Entidade 
            WHERE m.ID_Turma = :P62_ID_TURMA
            ```
        *   Coluna `ENVIAR`: Mude para **Checkbox**.
    *   **Processo de Envio (PL/SQL):**
        *   No Processing, crie um processo `Enviar Emails`.
        *   Código:
            ```sql
            BEGIN
               -- Iterar pela Grid gerrada
               CASE :APEX$ROW_STATUS
                 WHEN 'U' THEN -- Apenas linhas atualizadas/submetidas
                   IF :ENVIAR = 'S' THEN
                      -- Chamar nossa procedure mágica
                      PKG_COMUNICACAO.Agendar_Email(
                          p_para => :EMAIL,
                          p_assunto => 'Notificação Academia', -- Idealmente buscar do modelo
                          p_corpo => PKG_COMUNICACAO.Processar_Template(:P62_MODELO, :ID_ENTIDADE, :P62_ID_TURMA),
                          p_data_agendada => :P62_DATA_AGENDAMENTO,
                          p_origem => 'TURMA:' || :P62_ID_TURMA
                      );
                   END IF;
               END CASE;
            END;
            ```
        *   *Nota Técnica:* Para IG loops funcionarem, o IG deve ter "Edit" ativo, mas podemos esconder a toolbar.

## Parte 4: Automação ("O Piloto Automático")

Para garantir que os emails agendados saem:

1.  Vá a **App Builder > Shared Components**.
2.  Sob "Workflows and Automations", clique em **Automations**.
3.  **Create Automation:**
    *   **Name:** `Processar Fila de Emails`.
    *   **Type:** `Scheduled`.
    *   **Execution Schedule:** `Every 15 Minutes`.
4.  **Action:**
    *   **Type:** `Execute PL/SQL Code`.
    *   **Code:** `PKG_COMUNICACAO.Processar_Fila;`
5.  Salve e ative.

Agora, o sistema automaticamente verifica a tabela `Log_Comunicacoes` e envia o que estiver na hora!
